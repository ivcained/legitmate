# LegitMate demo — 170 seconds

## Recording setup

- Open `https://mate.legitclub.com/` in a clean browser.
- Use UI Designer and the default model.
- Keep one successful deployment recording as a fallback for provisioning wait time.
- Hide browser extensions, tokens, signed URLs, and personal wallet data.

## Required fallback cuts

- If provisioning is slow, cut from the real launch click to a clearly labeled earlier successful run from the same submitted build.
- If the Graph request fails, show the failure. Do not use fixtures or call it live.
- Never splice a result from a different instance onto the current receipt.

## Claims to avoid

- No autonomous employee claim.
- No guaranteed performance, views, profit, or safety.
- No real payment or transaction claim unless a receipt is shown.
- No composable/standardized Graph prize claim; this build targets the AI Use Case Start Fresh track.
- The readiness check is fixed and read-only, not arbitrary agent work.
- Exact-once creation across multiple server processes is not guaranteed.
